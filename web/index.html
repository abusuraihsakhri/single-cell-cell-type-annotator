Single-cell RNA-seq · Exploratory annotation

Cell-type marker overlap annotator

Compare cluster marker genes with your own reference signatures using a one-sided hypergeometric test and Benjamini–Hochberg false discovery rate adjustment.

Runs entirely in your browser. No file uploads to a server, third-party databases, model calls, or external scripts.

1. Cluster markers

CSV with columns cluster,gene; use one gene per row. Duplicates are removed.

2. Reference signatures

CSV with columns cell_type,gene. Supply provenance-matched marker lists for the tissue/species.

3. Background universe

Enter all genes eligible for testing (e.g., expressed/tested genes), one per line or comma-separated. Never use only the union of hits as the background.

Provide your data or load the synthetic example, then run annotation.

Annotation results

Rows are sorted by cluster, adjusted p-value, then overlap. Green rows mark the best eligible match.

Statistical interpretation: Tests use the hypergeometric upper tail with a fixed supplied universe; BH correction is performed separately within each cluster, over all reference types supplied. A significant overlap is not a calibrated posterior probability or proof of cell identity. No built-in HCA, PanglaoDB, CellTypist, or expression-level analysis is included.
